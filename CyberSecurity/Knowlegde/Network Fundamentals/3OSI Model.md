#### What is the OSI Model
OSI Model คืออะไร ?
OSI Model (Open Systems Interconnection Model) คือ รูปแบบการสื่อสารโครงสร้างแบบแนวคิดที่แบ่งหน้าที่การสื่อสารออกเป็น 7 ชั้น เพื่อกำหนดมาตรฐานการสื่อสารระหว่างอุปกรณ์ที่ต่างยี่ห้อให้ทำงานร่วมกันได้ เข้าใจกระบวนการรับ/ส่งข้อมูล

#### Layer 1 - Physical
Physical คือ ชั้นที่พูดถึงส่วนประกอบทางกายภาพ (Physical components )ของ Hardware ซึ่งเป็นชั้นล่างสุดจาก 7 ชั้น
โดยชั้นนี้ใช้สัญญาไฟฟ้าในการแลกเปลี่ยนข้อมูลกับในรูปแบบระบบฐาน 2 (Binary numbering system) คือ 0 กับ 1 นั่นเอง
ตัวอย่างเช่น สาย Ethernet ของอุปกรณ์ที่เชื่อมเข้าด้วยกัน
![[Pasted image 20260327144223.png]]
#### Layer 2 - Data Link
Data Link Layer เป็นชั้นที่โฟกัสไปยังการระบุที่อยู่ทางกายภาพ
โดยมันจะทำ Packet ที่มาจาก Network Layer ซึ่งมี IP address อยู่ จากนั้นมันจะทำการเติม MAC เข้าไป

 ภายในคอมพิวเตอร์ที่เชื่อม network ได้ จะมีอุปกรณ์ที่เรียกว่า Network interface Card (NIC) หรือ การ์ดแลน ติดตั้งมาด้วย ซึ่งมาพร้อมกับ MAC address เฉพาะตัวเพื่อใช้ในการระบุตัวตน

#### Layer 3 - Network
Network Layer คือ ชั้นของ Routing และ การนำข้อมูลกลับมารวมกัน
กระบวนการทำงานในชั้นนี้ อย่างแรกคือ Routing จะค้นหาเส้นทางในการส่งข้อมูลที่ดีที่สุด โดยใช้ Protocol ในการค้นหา ซึ่ง Protocol ที่ใช้ค้นหา เช่น OSPF (OPEN Shortest Path First) และ RIP (Routing Information Protocol) โดยปัจจัยที่ใช้ในการตัดสินใจมีดังนี้
- เส้นทางไหนสั้นสุด : จำนวนอุปกรณ์ที่ Packet ต้องเดินทางผ่านน้อยที่สุด
- เส้นทางไหนปลอดภัยที่สุด : เคยมีข้อมูลหล่นหายไปรึป่าว
- เส้นทางไหนเชื่อมต่อทางกายภาพเร็วที่สุด : เส้นหนึ่งใช้สายทองแดง (ช้ากว่า) และ อีกเส้นใช้สายไฟเบอร์ (เร็วกว่า)
เลเยอร์นี้จะจัดการทุกอย่างผ่าน IP address โดยอุปกรณ์อย่าง  Router ที่จะส่ง Packet ผ่าน IP address ได้

#### Layer 5 - Session Layer 
- สร้างและรักษาการเชื่อมต่อ : หลังจากข้อมูลที่ถูกจัดการมาจาก Layer 6 แล้วมาที่ Layer นี้ Layer นี้จะทำการสร้างการเชื่อมต่อไปยังเครื่องปลายทาง เมื่อเชื่อมต่อสำเร็จจะเรียกสิ่งที่เกิดว่า session
- ควบคุมระยะเวลาการใช้งาน : คอยดูแล session ให้ทำงานเท่าที่ยังมีการส่งข้อมูล และจะปิดตัวถ้าไม่ได้ใช้งานนานๆ
- ระบบ Checkpoints : แบบช่วยในกรณีที่เน็ตหลุด หากมีการทำเครื่องหมายไว้ เราก็ไม่จำเป็นต้องส่งข้อมูลไปใหม่ทั้งหมด แค่ส่งส่วนที่ขาดหายไปเท่านั้นเอง
- ความเป็นส่วนตัว : แต่ละ session จะแยกออกจากกัน ข้อมูลแต่ละ session จะไม่ปนกัน
#### Layer 6 - Presentation Layer
Presentation ทำหน้าที่จัดการ รูปแบบของข้อมูล เพื่อให้มั่นใจว่าระบบจะสามารถเข้าใจข้อมูลนั้นได้จริงๆ
- ตัวแปรภาษา : แปลงข้อมูลระหว่างรูปแบบที่ Network เข้าใจ กับ รูปแบบที่ Application เข้ากัน 
- ทำให้เป็นมาตรฐานเดียวกัน
- ความปลอดภัย : มีการเข้ารหัสของข้อมูล
- การบีบอัด : มีการบีบอัดข้อมูลให้เล็กลงก่อนส่งไป เพื่อให้มีประสิทธิภาพในการสื่อสาร
#### Layer 7 - Application
Application Layer คือชั้นที่ใกล้ชิดกับ User มากที่สุด และเป็นจุดเริ่มต้นและจุดสิ้นสุดของการรับ-ส่งข้อมูลอีกด้วย
- ส่วนต่อประสารกับผู้ใช้ : ทำหน้าที่กำหนดสิ่งต่างๆ ได้แก่ Protocol Roles ในการรับ-ส่งของข้อมูล
- เป็นที่อยู่สำคัญของ Protocol : ได้แก่ 
  - HTTP / HTTPS : สำหรับท่องเว็บไซต์
  - SMTP / IMAP : สำหรับการรับ-ส่งอีเมล
  - FTP : สำหรับโอนไฟล์
  - DNS : ทำหน้าที่แปลชื่อเว็บ ให้เป็น IP address เพื่อให้คอมพิวเตอร์คุยกันได้
