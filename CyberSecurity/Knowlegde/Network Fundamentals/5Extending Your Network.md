#### Port Forwarding
Port Forwarding คืออะไร ?
คืือ การตั้งค่า Router เพื่อให้อุปกรณ์ภายใน (Internet) สามารถเข้าถึงการใช่บริการต่างๆ (web , application) ที่รัน server อยู่ในเครือข่ายภายใน (Private Network/LAN)ได้

หลักการทำงาน ?
1. Request : User จะส่งข้อมูลมาที่ Public IP ของ Router เราพร้อมระบุ Port เช่น 82.62.51.70:80
2. Intercept :  Router ได้นับข้อมูลและตรวจสอบตาราง Forwarding ที่เราได้ตั้งค่าไว้
3. Redirection : Rounter ส่งต่อข้อมูลไปที่ Internal IP และ Port ของเครื่องเป้าหมายในวงเลน เช่น 192.168.1.10:80
4. Connection : เครื่องเป้าหมายตอบกลับ ข้อมูลวิ่งย้อนกลับทางเดิมไปหา User

ความแตกต่าง Port Forwarding กับ Firewall ?
- Port Forwarding : คือการ"ชี้ทาง"(Routing) บอกว่าประตูไหนไปหาใคร
- Firewall : คือการ"ตรวจบัตร"(Filtering)ว่าจะยอมให้ข้อมูลนั้นผ่านประตูที่เปิดไว้หรือไม่ (ต่อให้ทำ Port Forwarding แล้วก็ตาม แต่ถ้า Firewall บล็อคก็เข้าไม่ได้)

ทำไมต้องใช้ ?
- Hosting Services : เปิด Web server , FTP หรือ Game Server (เช่น Minecraft) ให้เพื่อนจากข้างนอกเข้ามาจอยกับเราได้
- Remote Access : ใช้ SSH หรือ RDP เพื่อคุมคอมพิวเตอร์ที่บ้านจากที่ทำงานได้
- IoT/CCTV : ดูภาพจากกล้องวงจรปิดผ่านอินเทอร์เน็ตได้

ข้อควรระวังด้าน Security ?
- Insecure Port : การเปิด Port ทิ้งไว้โดยไม่จำเป็น เสี่ยงต่อการถูก Scan Port และ Attack ได้
- Best Practice : เปิดเฉพาะ Port ที่จำเป็น
	- ใช้ Port ที่ไม่ใช่มาตรฐาน เพื่อหลีกเลี่ยงการสแกนอัตโนมัติ เช่น SSH จาก 22 เป็น 2222
	- อัพเดต Patch ของแอปอยู่เสมอ
#### Firewall 101
Firewall คืออะไร ?
คือ "หน่วยตรวจตรา รักษาความปลอดภัยชายแดน" โดยจะเป็นคนคอยตรวจสอบข้อมูล (Packet Inspection) เพื่อตัดสินใจว่าจะ Permit อนุญาต หรือ Deny ปฏิเสธ

ปัจจัยที่ Firewall ใช้พิจารณา ?
- source : ข้อมูลมาจากที่ไหน (IPไหน / Networkอะไร)
- Destination : ข้อมูลกำลังจะไปที่ไหน
- Port : ข้อมูลจะเข้าทาง Port ไหน เช่น 80,443 ?
- Protocol : ข้อมูลใช้ Protocol อะไร เช่น TCP,UDP

ประเภทของ Firewall ?

| ประเภท    | คำอธิบาย                                                    | ข้อดี/ข้อเสีย                                                                          |
| --------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Stateful  | ดูข้อมูลทั้งหมดแบบไม่แยกเป็นชิ้น ดูพฤติกรรมโดยรวมแบบละเอียด | ข้อดี : ฉลาด ตรวจจับพฤติกรรมได้เม่นยำ<br>ข้อเสีย : ใช้ทรัพยากร                         |
| Stateless | ดูข้อมูลแยกเป็นส่วนๆ ดูตามกฎที่ตั้งไว้แบบตายตัว             | ข้อดี : ทำงานเร็วมาก เหามะกับทราฟฟิกมหาศาล(สามมาป้องกัน DDos)<br>ข้อเสีย : ไม่ยืดหยุ่น |
- Statefull  คือ รปภ. ที่เข้มงวด รู้หมดว่า คุณทำอะไร ที่ไหน กับใคร
- Stateless คือ รปภ.ที่ตรวจบัตรอย่างเดียว แค่มีบัตรก็ผ่านได้
#### VPN Basics
VPN คืออะไร ?
VPN(Virual Private Networking) 
คือ เทคโนโลยีที่ทำให้อุปกรณ์ที่อยู๋คนละ Network สามารถคุยได้กันอย่างปลอดภัยผ่าน Internet โดยมีการสร้างเส้นทางเชื่อมต่อกันโดยเฉพาะเรียกว่า Tunnel (อุโมงค์) ทำให้เหมือนอุปกรณ์พวกนี้อยู่ใน Network เดียวกัน
![[Pasted image 20260406152006.png]]

ประโยชน์ของ VPN ?
- การเชื่อมต่อข้ามพื้นที่ : เช่น ช่วยให้สาขาของบริษัทต่างๆสามารถเข้าถึงทรัพยากรส่วนกลาง (server) ได้จากทุกที่
- ความเป็นส่วนตัว (Privacy):  มีการเข้ารหัส (Encryption) เพื่อป้องกันการดักฟังข้อมูล (Sniffing) โดยเฉพาะเวลาใช้ Public WiFi
- การปกปิดตัวตน (Anonymity) : ช่วยให้รอกจากการตรวจสอบ ISP ของผู้บริการอินเตอร์เน็ต 

เทคโนโลยีของ VPN ?
- PPP : ใช้ในการ Authentication (การยืนยันตัวตน) และ เข้ารหัสข้อมูลโดยใช้ Private Key และ Public Certificate ในการตรวจสอก่อนเชื่อมต่อ
- PPTP : เป็นโปรโตคอลที่ทำให้ข้อมูลจาก PPP วิ่งออกไปนอก Network ได้ 
	- ข้อดี : ตั้งค่าง่าย รองรับแทบทุกอุปกรณ์ 
    - ข้อเสีย : การเข้ารหัสค่อนข้างอ่อนแอเมื่อเทียบกับตัวอื่น
- IPSec : เข้ารหัสข้อมูลโดยใช้โครงสร้างของ IP โดยตรง
	- ข้อดี : ปลอดภัยสูง
	- ข้อเสีย : setting ยาก
#### LAN Networking Devices
Router คืออะไร ?
![[Pasted image 20260406155531.png]]
router มีหน้าที่ในการเชื่อมต่อ network ต่างๆเข้าด้วยกัน และส่งข้อมูลเหล่านั้นผ่านกระบวนการที่เรียกว่า Routing 
- ระดับการทำงงาน : Layer 3 (Network Layer) OSI Model
- การตัดสินใจ : Router จะเลือกเส้นทางที่ดีที่สุดโดยมีเงื่อนไงในการตัดสินใจ
	- เส้นทางไหนสั้นสุด
	- เส้นทางไหนเสถียรสุด
	- เส้นทางไหนเร็วสุด (ไฟเบอร์ VS สายทองแดง)
- ความสามารถ : มักจะมี Interface เช่น Website ตั้งค่า ให้ Admin เข้าไปจัดการกฎต่างๆ เช่น Port Forwarding หรือ Firewall

Switch คืออะไร ?
![[Pasted image 20260406155543.png]]
switch ตัวสลับสัญญาณ 
คือ อุปกรณ์ที่ทำหน้าที่เป็นจุดเชื่อมต่อให้อุปกรณ์หลายๆเครื่อง โดยมาเสียบสาย LAN เข้าด้วยกันภายใน Network เดียวกัน
ความแตกต่างในการทำงานใน Layer 2 and 3 OSI model
- Layer 2 : ส่งข้อมูลกันในรูปแบบ Frames โดยอ้างอิงจาก MAC address ของอุปกรณ์ที่เชื่อมต่อยู่เท่านั้น ไม่สามารถทำงานในระดับ IP ได้
- Layer 3 : มีความเก่งกว่า ตรงที่สามารถทำหน้าที่บางอย่างของ Router ได้ เช่น การส่ง Packet โดยใช้ IP Protocol และจัดการการรับส่งข้อมูลระหว่างวง Network ได้

เทคโนโลยี VLAN ?
![[Pasted image 20260406155559.png]]
VLAN หรือ Virtual Local Area Network
คือ เทคโนโลยีที่ช่วยให้สามารถ"แบ่งกลุ่มเสมือน"ให้อุปกรณ์ที่อยุ่ใน switch เดียวกันแยกออกจากกันได้ เพื่อความปลอดภัยและความเป็นระเบียบ
- ตัวอย่าง : แผนก Sale และ Accounting ที่อยู่บน Switch ตัวเดียวกัน แยกกันโดยถูกแบ่งโดย VLAN
- ผลลัพธ์ : ทั้งสองแผนกเล่น Internet ได้ตามปกติ แต่ไม่สามารถติดต่อสื่อสารกันข้ามแผนกได้ เว้นแต่จะตั้งกฎอนุญาตไว้

สรุปภาพรวม ?
Router : เชื่อมระหว่างหมู่บ้าน
Switch : เชื่อมต่อ  บ้าน ในหมู่บ้านเดียวกันให้คุยกันได้
VLAN : เป็นรั้วกั้นบ้านภายในหมู่บ้าน
