### what is networking 

networking คือ การเชื่อมต่อสิ่งต่างๆแบบง่ายๆ  เช่น ความสัมพันธ์ของเรากับเพื่อน เราจะเชื่อมกันเพราะมีสิ่งที่สนใจ งานอดิเรก เหมือนกัน 
networking ที่พบได้ในชีวิตประจำวัน
- ระบบขนส่งสาธารณะ
- โครงสร้างพื้นฐาน เช่น ไฟฟ้า
- การพูดคุยและทักทายกับเพื่อน
- ไปรษณีย์ในการส่งจดหมายและพัสดุ

#### what is the internet 

internet คือ การรวมตัวกันของ networking เล็กๆจำนวนมากมาย หลายๆกลุ่ม รวมตัวกันจดเป็นระบบเครือข่าย เพื่อติดต่อสื่อสารกัน

#### Identifying Devices on a Network
ในการสื่อสารนี้เราก็ต้องรู้ว่าคนที่เราคุยคือใคร ไม่งั้นเราจะคุยไปทำไหม
ที่นี้ ในการระบุตัวตนเนี้ย ถ้าในคนเราจะมีด้วยกันอยู่ 2 อย่างคือ
- ชื่อ
- ลายนิ้วมือ
ซึ่ง ชื่อ เป็นสิ่งที่สามารถเปลี่ยนแปลงได้ แต่ ลายนิ้วมือ ไม่สามารถเปลี่ยนแปลงได้เป็นเอกลักษณ์เฉพาะคน ส่วนคอมพิวเตอร์ก็คล้ายกัน คือมีด้วยกัน 2 ส่วนคือ
- IP Address
- MAC Address
#### IP Address 
IP address (Internet Protocol) มันถูกใช้เพื่อระบุตัวตนใน internet
โดย IP address มันสามารถเชื่อมต่อกับ IP address อื่นได้โดยไม่มีการเปลี่ยน IP address
องค์ประกอบของ IP address
![[Pasted image 20260324201428.png]]
IP คือ ชุดดตัวเลขที่ถูกแบ่งออกเป็น 4 octets. 
ซึ่งค่าในแต่ละ octets มันจะรวมกันเป็น IP address ที่ใช้ใน internet ซึ่งตัวเลขนี้ผ่านการคำนวณเทคนิค ชื่อ IP addressing & subnetting 
IP address สามารถเปลี่ยนจากอุปกรณ์หนึ่งไปอีกอุปกรณ์ แต่ไม่สามารถทำงานพร้อมกันได้ใน networking เดียวกัน

IP address จะถูกกำหนดรูปแบบให้เหมือนกันเรียกว่า Protocols.
protocols เป็นหัวใจหลักของ internet และ มันบังคับให้ทุกเครื่องต้องติดต่อสื่อสารในภาษาเดียวกัน 
อุปกรณ์เหล่านั้นจะสามารถเชื่อมกันได้ทั้งกับ private networking และ public networking 

public address จะถูกใช้เพื่อระบุตัวตนในอินเทอร์เน็ต ส่วน Private address จะใช้ระบุตัวตนระหว่างเครื่อง

MAC address
อุปกรณ์จะมีแผงวงไมโครชิปอยู่ที่เมนบอร์ด ซึ่งมันจะถูกกำหนดที่อยู่เฉพาะตัว (Unique address) ให้มาตั้งแต่โรงงาน ซึ่งเราจะเรียกว่า MAC address (MAC = Media Access Control)

MAC address คือ ตัวเลขฐานสิบหก 12 หลัก (ระบบตัวเลขฐาน 16 ี่ใช้ในงานคอมพิวเตอร์เพื่อแสดงค่าตัวเลขโดยจะแบ่งออกเป็นคู่ และ คั่นด้วยเครื่องหมาย โคลอน (:) ซึ่งทำหน้าที่เป็นตัวแบ่ง ตัวอย่างดังภาพ)
![[Pasted image 20260324235432.png]]
- 6 หลักแรก : เป็นตัวเลขของบริษัทที่ผลิต
- 6 หลักหลัง : เป็นหมายเลขระบุที่ไม่ซ้ำกัน

สิ่งที่น่าสนใจเกี่ยวกับ MAC address คือการปลอมเป็น MAC address ของเครื่องอื่น
ยกสถานการณ์จำลอง เช่น Firewall ที่ถูกตั้งค่าให้สื่อสารแค่เฉพาะ MAC address ของผู้ดูแลระบบ แต่มีผู้ไม่หวังดีปลอมแปลงว่าตัวเองคือ MAC address ผู้ดูแลระบบ Firewall จะอนุญาตให้สื่อสาร

#### Ping(ICMP)
Ping เครื่องมือพื้นฐานในระบบเครื่องข่าย โดย Ping จะใช้ ICMP (internet control message protocol) ในการตรวจว่ามีการเชื่อมมต่ออยู่จริงไหม และมีความเร็ว ความเสถียรในการเชื่อมต่อมากแค่ไหน
