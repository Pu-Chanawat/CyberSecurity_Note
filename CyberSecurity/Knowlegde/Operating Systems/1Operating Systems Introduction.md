#### Introduction
**เป้าหมายการเรียนรู้ (Learning Objectives)**
- ทำความเข้าใจว่าระบบปฏิบัติการ (Operating System) คืออะไร และมีบทบาทหน้าที่อย่างไร
- อธิบายหน้าที่หลักของระบบปฏิบัติการ
- ระบุประเภทของ OS ที่พบบ่อยและกรณีการใช้งานทั่วไป
- ฝึกฝนการโต้ตอบกับ OS เพื่อรวบรวมข้อมูลของระบบ

#### The Invisible Manager
**ระบบปฏิบัติการ (Operating System หรือ OS)**
คือ  ซอฟต์แวร์หลักของเครื่องคอม ที่คอยจัดการประงานทุกอย่างเข้าได้ด้วย โดยมันจะอยู่ตรงกลางระหว่าง User (ผู้ใช้งาน) , แอปพลิเคชั่น (Application) และ ฮาร์ดแวร์ (Hardware) ของระบบ ทำหน้าทีเป็นผู้จัดการให้ทั้งเครื่องสามารถทำงานร่วมกันได้

เปรียบเทียบการทำงานของ OS กับสนามบิน
 - Hardware (CPU,RAM,พื้นที่จัดเก็บข้อมูล,อุปกรณ์เชื่อมต่อ) :
   เปรียบเทียบได้กับ รันเวย,ตัวเครื่องบิน,ระบบเชื้อเพลิง,เรดาร์ โครงสร้างพื้นฐานต่างๆ บลาๆ
 - Application (Website,Game) :
   เปรียบเทียบได้กับ สายการบินต่างๆ และผู้โดยสารที่ใช้บริการ
 - OS (Windows,Linux,macOS) :
   เปรียบได้กับ  หอบังคับการบิน ที่คอยควบคุมการจราจรทางอากาศ ทั้งหมด ค่อยสั่งการ จัดตารางการใช้ทรัพยากร จัดการจราจร แก้ไขความขัดแย้ง และดูแลความปลอดภัย
**เลเยอร์สิทธิ์ของระบบ (System Privilege Layers**
ภายใต้คอมพิวเตอร์ ส่วนต่างๆของระบบจะทำงานภายในระดับสิทธิ์ (Permission Levels) ที่แตกต่างกัน โดยบางอย่างสามารถติดต่อกับ Hardware ได้โดยตรง แต่บางส่วน เช่น แอปพลิเคชั่นถั่วไป ทำได้แค่รันในสภาพแวดล้อมที่จำกัด การแยกส่วนแบบนี้ก็เพื่อป้องกันความขัดแย้งกันและเพื่อความปลอดภัย
สิทธิ์ก็จะมีดังนี้
- Kernel Space :
   เป็นส่วนที่สามารถติดต่อกับ Hardware ได้ด้วยตรง
- User Space :
  เป็นส่วนที่แอปพลิเคชั่นทำงานอยู่ มีการจำกัดการเข้าถึง Hardware บางส่วน
**หน้าที่ของระบบปฏิบัติการ (Operating System DUties)**

| หน้าที่                                         | สิ่งที่ทำ                                                                                                                                                                                  | ตัวอย่าง                                                                                                |

| การจัดการอุปกรณ์ ( Device management)           | โหลดไดรเวอร์และเตรียม Interface มาตรฐาน เพื่อให้แอปสั่ง พิมพ์งาน ได้ หรือ เล่นเสียงนี้ได้ทันที                                                                                             | การเสียบเมาส์ใหม่<br>เครื่องพิมพ์<br>หรือ Hardware ภายนอก แล้วมันใช้งานได้ทันที                         |
**ความมั่นคงและปลอดภัยของระบบปฏิบัติการ (Operating System Security)**
- การยืนยันตัว (Authentication)
  ตรวจสอบว่าคุณคือใครผ่านการล็อคอิน
- การกำหนดสิทธิ์ (Permissions)
  ควบคุมว่าคุณมีสิทธิ์ใช้งานอะไร
- การแยกส่วน (Isolation)
  เก็บทุกโปรเซสไว้ในกล่องของตัวเอง (แยกระหว่าง Kernel กับ User space)
- การป้องกันระบบ (System Protection)
  ป้องกันไฟล์ระบบและการตั้งค่าที่สำคัญจากการถูกเปลี่ยนแปลงโดยไม่ได้รับอนุญาต
