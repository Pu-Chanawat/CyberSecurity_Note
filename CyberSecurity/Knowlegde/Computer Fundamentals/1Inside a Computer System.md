#### Inside a Computer System
ส่วนประกอบของคอม 1 เครื่อง
- CPU (The Brain) เหมือน สมอง ใช้คิดคำนวณ วิเคราะห์ทุกอย่างในเครื่อว
- RAM (Short-term Memory) เหมือน ความจำระยะสั้น ใช้เก็บข้อมูลที่กำลังใช้งานอยู่เพื่อเรียกว่าใช้งานได้ไว
- HHD + SSD (Long-term Memory) เหมือน ความจำระยะยาว ใช้เก็บข้อมูล ไฟล์ต่างๆ
- Motherboard (The Skeleton and Nerves) เหมือน โครงกระดูกและระบบประสาท เป็นแกนหลักเชื่อมโยงส่วนอื่นๆเข้าด้วยกัน
- PSU (Heart and Lougs) เหมือน หัวใจและปอด คอยให้พลังงานกับอุปกรณ์
- GPU (Visual Cortex) เหมือน ส่วนประมวลผลการมองเห็น เน้นจัดการเรื่องภาพ กราฟิก
#### What happens when you press the start button?
1. กดเปิดเครื่อง (Power Button)
	   เมื่อเรากดปุ่ม สัญญาณจะถูกส่งไปที่ PSU เพื่ออนุญาตให้กระแสไฟไหลเข้าสู่ระบบ
2. Firmware เริ่มทำงาน
	 ซอฟต์แวร์ฝังตัวที่เรียกว่า **Firmware** คอยปลุกให้อุปกรณ์ทุกชิ้นเริ่มขยับ ระบบหลักที่จัดการเรื่องนี้เรียกว่า **UEFI** (หรือที่เรามักจะได้ยินชื่อเก่าว่า **BIOS** ซึ่งทำหน้าที่เหมือนกันแต่ UEFI ทันสมัยกว่าครับ)
3. ตรวจจสอบความพร้อม (Power-On Self Test หรือ POST)
	เมื่อระบบเริ่มทำงานแล้ว จะเริ่มทดสอบว่าอุปกรณ์ทุกตัวทำงานปกติไหม โดยจะทำการ Post เพื่อเทส ถ้ามีตัวไหนพัง ก็จะมีการส่งสัญญาณเสียงเตือน เช่น เสียงปี๊บ
4. เลือกอุปกรณ์สำหรับบูต (Select Boot Device)
	UEFI จะค้นหาว่าระบบปฏิบัติการ (Windows/Linux) เก็บไว้ที่ไหน
5. เริ่มใช้งาน Bootloader
	ตัว Bootloader จะทำหน้าที่ดึง OS ขึ้นมาวางบน RAM แล้วคืนอำนาจ
