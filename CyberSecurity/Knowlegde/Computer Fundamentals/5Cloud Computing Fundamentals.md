#### Cloud Computing Overview
**Cloud Computing คืออะไร?**
คือ การเช่าใช้ทรัพยากรคอมพิวเตอร์ผ่านอินเตอร์เน็ต
**คุณสมบัติเด่นของ Cloud**
- Scalability : ปรับขนาดขึ้นลงได้ง่ายตามความต้องการของแอพ
- On-demand self-service : สร้างหรือลบ Server และพื้นที่ได้ทันที โดยไม่ต้องรอ Hardware จริง
- Pay only for what you use : ใช้เท่าไหน จ่ายเท่านั้น
- Security : ผู้ให้บริการมีการป้องกันให้
- Global access :  ทุกคนทั่วโลกสามารถเข้าถึงได้
**ประเภทของ Cloud**
- Public Cloud 
- Private Cloud
- Hybrid Cloud
การเปรียบเทียบ: บ้าน (Private) กับ โรงแรม (Public)
- **บ้านของคุณ (Private Cloud):** คุณมีห้องนอนที่เก็บความลับทุกอย่างไว้ คุณรู้สึกปลอดภัยที่สุด แต่บ้านคุณรับแขกได้แค่ 5 คน
- **โรงแรม (Public Cloud):** มีห้องพักเป็นร้อยห้อง ใครๆ ก็ไปเช่าอยู่ได้ (แชร์ทรัพยากรกัน) ถ้าคุณจะจัดงานปาร์ตี้ใหญ่ๆ โรงแรมรับคนได้สบาย
พอเป็น **Hybrid Cloud (แบบผสม)** จะทำงานแบบนี้ครับ
คุณอาศัยอยู่ในบ้านตามปกติ (เก็บข้อมูลส่วนตัว/สำคัญไว้ที่นี่) แต่พอถึงวันเกิดคุณ มีเพื่อนจะมาหา 100 คน บ้านคุณรับไม่ไหว คุณเลยไป **เช่าห้องจัดเลี้ยงที่โรงแรม** เพิ่มเติมเพื่อรองรับเพื่อนเหล่านั้นชั่วคราว พอปาร์ตี้จบ คุณก็เลิกเช่าโรงแรม แล้วกลับมาใช้ชีวิตในบ้านแคบๆ ของคุณเหมือนเดิม
  
**รูปแบบการให้บริการ (Service Models)**

| รูปแบบ                                | เนื้อหา                                                                                            | เปรียบเทียบ     |
| ------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------- |
| IaaS<br>(Infrastructure as a Service) | เขาให้แค่เครื่องเปล่ามา คุณต้องลง OS เอง , ลงโปรแกรมและจัดการความปลอดภัยเอง                        | เช่าบ้านเปล่า   |
| PaaS<br>(Platform as a Service)       | เขาเตรียมระบบหลังบ้านไว้ให้แล้ว เราแค่เขียนโค้ดแล้วเอาไปวางไว้ (เหมาะมากกับโปรเจกต์ React/Next.js) | เช่าอพาร์ตเมนต์ |
| SaaS<br>(Software as a Service)       | เป็นแอปพลิเคชั่นสำเร็จพร้อมใช้ (Gmail , Google Drive)                                              | เช่าโรงแรม      |
