#### **Pizza Delivery**
เปรียบเทียบ "การทำงานของคอมพิวเตอร์" กับ "การสั่ง Pizza"

**การสั่ง Pizza**
ในคืนวันศุกร์
แฟนอยากกิน  pizza เลยสั่ง แฟนเลยบอกกุว่าอยากกิน pizza หน้าอะไร กุก็ต้องออกไปซื้อ pizza โดยทำการพิมพ์ชื่อร้านใน google map ก็ได้ตำแหน่งร้านมา แล้วก็ขับไปที่ร้าน จากนั้นพอถึงร้านก็ เดินเข้าช่องประตูสำหรับสั่งกลับบ้าน แล้วสั่งว่า "ขอพิซซ่าเปปเปอโรนีถาดใหญ่กับโค้กหนึ่งขวด" พนักงานรับออเดอร์แล้วเริ่มทำ เมื่อเสร็จแล้วบ็อบก็นำพิซซ่ากลับบ้านไปกิน

เปรียบกับ **การทำงานของคอมพิวเตอร์**
1. Service,Client,Server
	- Client คือ แฟนกุที่เป็นคนสั่งพิซซ่า
	- Server คื ร้านพิซซ่า
2. Request,Response
	- แฟนกุขอพิซซ่า Request
	- ร้านพิซซ่าทำให้ Response
3. Protocol
	คือ ภาษากลาง และ ระเบียบการสั่ง แฟนกุต้องสั่งตามภาษาที่ร้านเข้าใจ แบบ
	- คำสั่งไหนที่เข้าใจ เช่น GET เพื่อขอข้อมูล
	- โครงสร้างภาษาแบบไหน
4. Port (ประตูบริการ)
	 Port คือการระบุว่าจะเข้าประตูไหน
	 ลองนึกภาพร้านพิซซ่ามีหลายประตูบริการ ประตู A สำหรับสั่งกลับบ้าน, ประตู B สำหรับนั่งทานที่ร้าน, ประตู C สำหรับเดลิเวอรี่ คอมพิวเตอร์หนึ่งเครื่องก็รันหลายบริการได้พร้อมกัน (เช่น เว็บ, อีเมล, โอนไฟล์) โดยแต่ละบริการจะมี "หมายเลขประตู" หรือ Port ที่ต่างกันนั่นเอง
5. DNS
	ตอนแฟนบอกชื่อร้าน กุยังไปไม่ถูกจนกว่าจะพิมพ์ชื่อนั้นลงใน GPS เพื่อให้ได้ "พิกัด" ออกมา **DNS** ทำหน้าที่เหมือน GPS ครับ เมื่อเราพิมพ์ชื่อเว็บ (Domain Name) DNS จะเปลี่ยนชื่อนั้นให้เป็น **IP Address** (เช่น 192.168.1.1) ซึ่งเปรียบเสมือนบ้านเลขที่ของเซิร์ฟเวอร์เพื่อให้คอมพิวเตอร์เดินทางไปหาถูกครับ
