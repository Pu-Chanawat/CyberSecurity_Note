#### Putting It All Together

สรุปภาพรวมการทำงาน
1. ขั้นที่ 1 การค้นหาที่อยู่ : เริ่มต้นเราจะใช้ DNS เปลี่ยนชื่อโดเมน (เช่น Google.com ) ให้กลายเป็น IP Address ที่คอมคุยกัน
2. ขั้นที่ 2 การส่งคำขอ : ใช้ Protocols HTTP/HTTPS ส่ง Request ( Headers และ Cookies) ไปยัง Server
3. ขั้นที่ 3 การตอบกลับ :  Server ประมวลผล Back-End แล้ว Response ข้อมูลกลับมาในรูปแบบของรหัสสถานะ ( Status Codes ) และเนื้อหาไฟล์
4. ขั้นที่ 4 การแสดงผล : Browser ทำการแสดงผล Front-End

#### Other Components
- Load Balancer
	  ป้องกัน Server ทำงานนั้น และป้องกันล่มโดยการกระจายงานไปหลายๆเครื่อง
- CDN (Content Delivery Networks)
	  เน้นความเร็วในการโหลดโดยการนำไฟล์ไปวางไว้ใกล้ User ให้มากที่สุด โดยใช้ Server ที่ใกล้ที่สุด
- Database
	  เป็นส่วนหลังบ้านที่ใช้จัดเก็บและดึงข้อมูลกลับมาแสดงผล มีหลายประเภทตามใช้งาน
  
- WAF (Web Application Firewall)
	  เน้นเรื่องความปลอดภัย คัดกรองและสกัดกั้นการโจมตี (เช่น Bot หรือการยิงเว็บ) ก่อนถึงตัว Server
#### How Web servers work
Web Server คืออะไร ?
	คือ "Software ผู้ให้บริการ" ทำหน้าที่ในการรับออเดอร์และส่งออเดอร์ (หยิบไฟล์ในเครื่องส่งไปให้ Browser แสดงให้เราดู)
Virtual Hosts ?
	 คือ การ"แบ่งเช่า"  โดยปกติ 1 เครื่องคอม 1 Server แต่การทำ Virtual host คือทำให้ 1 เครื่อง หลายเว็บไซต์  ช่วยประหยัดทรัพยากร เพราะ ไม่ต้องซื้อ Server ใหม่ทุกครั้งที่ทำเว็บเพิ่ม
Static vs Dynamic Content ?
- Static Content คือ ข้อมูลที่อยู่นิ่ง ไม่มีการเปลี่ยนแปลง เช่น รูปภาพ, File Css,JS,หน้า HTML เขียนไว้แบบไหนก็โชว์แบบนั้น Serverไม่ต้องทำอะไรเพิ่มเลย
- Dynamic Content คือ ข้อมูลที่เปลี่ยนแปลงได้ เช่น หน้าแรกของ Blog ที่จะอัปเดต Post ล่าสุดขึ้นมา หรือ เปลี่ยนแปลงตามคำค้นหาของเรา
